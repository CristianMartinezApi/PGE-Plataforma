## Sobre o Projeto

A Plataforma PGE é um portal institucional desenvolvido para a Procuradoria Geral do Estado, oferecendo diversas ferramentas e funcionalidades para otimizar o trabalho dos procuradores e servidores.

### Principais Funcionalidades

- Gestão de Pautas de Processos
- Atos Normativos
- Documentos
- IA PGE
- Minerador de Processos
- Pareceres Jurídicos
- Administração de Usuários
